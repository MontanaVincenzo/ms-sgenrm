Please follow the steps (from this folder, `data_generation/01_input_request/02_tts_synthesis`):
* Clone the repo here: `git clone https://github.com/canopyai/Orpheus-TTS.git`
* Create the .venv with the dependencies in `orpheus_requirements.txt` plus the cloned package, from the repo root:
  `./setup_envs.sh orpheus`
* You can then run the batched_test.py script: `.venv/bin/python batched_test.py ...`
